## ✨ Features

- 📊 **System Monitor** - Real-time CPU, RAM, Disk usage
- 💻 **Web Terminal** - Execute bash commands from browser
- 📁 **File Explorer** - Browse, edit, upload files
- ⚙️ **Process Manager** - View and kill processes
- 🔧 **Service Control** - Start/stop systemd services
- 📜 **Event Logs** - Command history viewer
- 🌐 **Network Info** - Check all network interfaces
